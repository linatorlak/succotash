## Website files

No special build tools or external project images are required.

## Publish this repository with GitHub Pages
1. In this repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Set the branch to **main** and the folder to **/(root)**. Save.
4. Once publishing completes, check **https://linatorlak.github.io/succotash/**.

GitHub's guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
